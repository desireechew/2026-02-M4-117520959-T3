## Programa principal

Similar al protocolo visto en clase, la primera fase deberá enfocarse en la lectura y preparación de los datos previo a la etapa de entrenamiento.

Se espera que los estudiantes cumplan con los siguientes requisitos:

**Carga y limpieza de datos del archivo de entrada (formato CSV).**

Esto implica la definición explícita del *schema* y la inclusión de evidencias en el notebook que demuestren que los datos fueron cargados exitosamente.

**Gráficos y estadísticas descriptivas previas al entrenamiento.**
Se espera que los estudiantes presenten estadísticas descriptivas, correlaciones y cualquier otro análisis exploratorio relevante, con el objetivo de comprender mejor el conjunto de datos.

**Normalización / Estandarización.**
Los estudiantes deberán seleccionar e implementar alguna estrategia para mitigar los problemas de escala que puedan existir entre las diferentes columnas utilizadas por el modelo.

**Escritura a base de datos.**
Una vez que los datos hayan sido depurados, se espera que los estudiantes escriban en una tabla llamada `tarea3` (utilizando modo `overwrite`) el conjunto de datos que será utilizado como base para el entrenamiento de los modelos.

Los estudiantes deberán documentar en detalle cualquier instrucción necesaria para poder calificar esta sección.

Los datos almacenados en la base de datos no podrán estar representados en forma de vector; deberán mantenerse extraídos en columnas individuales.

## Entrenamiento de modelos

Se deberá cargar desde la base de datos el conjunto de datos limpio y entrenar dos modelos de clasificación (a escogencia de los estudiantes). Se espera que se utilice el protocolo estándar de K-Fold Cross Validation, además de reservar un conjunto adicional para validación final.

Los requisitos para esta sección son los siguientes:

* Uso del protocolo K-Fold Cross Validation, apoyándose en funciones provistas por Apache Spark.


* Entrenamiento de dos modelos de clasificación.

## Evaluación del conjunto de validación

Para cada uno de los modelos, se espera que los estudiantes realicen la evaluación correspondiente y generen una predicción persistente en la base de datos.

Dado que se evaluarán dos modelos, deberán crearse tablas llamadas `modelo1` y `modelo2` (utilizando modo `overwrite`) en la base de datos. Estas tablas deberán contener las mismas columnas presentes en `tarea3`, además de una columna adicional llamada `prediccion`, que mostrará el resultado predicho por cada modelo.

Asimismo, deberá incluirse un análisis de resultados dentro del notebook para cada modelo, comparando el desempeño obtenido. El análisis deberá aportar suficiente detalle sobre los resultados generados.

Los requisitos de esta sección son los siguientes:

* Evaluación y almacenamiento de `modelo1`.

* Evaluación y almacenamiento de `modelo2`.
